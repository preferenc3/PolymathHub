# Modelele de pronunție

Cele 13 replici originale în engleză, franceză și spaniolă au fost sintetizate înainte de publicare cu Kokoro-82M prin kokoro-onnx. Vocile sunt af_heart (engleză americană), ff_siwis (franceză) și ef_dora (spaniolă). Modelul și vocile sunt descrise în [fișa Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M). Site-ul redă fișierele MP3 la cerere. Textul replicilor se găsește în language-lessons.js și în dialogul din sql-course.js.
